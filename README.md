## Project: EUR Receivable FX Hedging Analysis (FIN 321)

A five-stage FX hedging project for a U.S. solar equipment exporter with a €3,947,368 receivable settling in one year. Each stage builds on the last: framing the exposure, specifying the model, building and auditing it in Excel, populating it with live market data, and validating the whole thing against an independently-run LLM analysis.
